THE PROCEDURES (code/ll.py)
Bonds   round 0 of the word learner (copied unchanged): genes labelled by rescue3 family when the family occurs in >= 2
        counting units; labelled pairs at distance 1-3 on one contig; n = units holding the pair, E = expected_groups
        (w 3), Lambda = n ln(n/E) - n + E; significant at n >= 2, Lambda >= tau (syn: Lambda N_eff / n >= tau, N_eff >= 2).
        tau = the word runs' tau* (1% word-type FDR): DPANN groups 10; Spacedust groups 10 (ladder rerun here: FDR .027 at
        8, .005 at 10; 87,698 word types); syn 8 on both. Each occurrence of a significant pair is a bond.
        DPANN: 39,137 significant pairs, 1,797,062 bonds (Lambda q50 64, q99 1,494), 36.6% of boundaries bonded; null
        corpora 14 / 9 / 10 pairs (62 / 30 / 36 bonds). Spacedust groups 140,823 pairs, 39.7% of boundaries; nulls
        418-465 pairs.
s_k     largest Lambda among bonds spanning boundary k.
L1      maximal runs of s_k > 0.        L2  L1 cut where kappa < theta (NaN = no cut).        L3  L2 UNION words V-mob.
L4      brief (a)-(d): s'_k = s_k, 0 where kappa < theta; tie-collapsed min-rooted Cartesian tree per run (union-find over
        boundaries in decreasing s'; equal minima split together, so every node has persistence > 0; checked against a
        brute force); kept at persistence >= delta, n >= 2, Lambda(n, E) >= tau_node, n = groups other than the node's
        own with a genome holding >= q distinct non-singleton families of the node within <= 2|I| genes on one contig,
        q = max(2, ceil(.5 |F_I|)); E literal (mean of 3 shuffled corpora; L4) or closed form (Poisson clumping with
        elementary symmetric polynomials; L4a). delta, tau_node: 1% node FDR against the whole procedure on 3 shuffles.
        Counts equal a brute-force window scan (0 / 120 mismatches). Closed-form E / shuffled count, summed over nodes:
        1.19 (DPANN), 1.002 (Spacedust).
L4+     L4's tree without test (c).
L4b     (amendment_2) the tree runs over the uncut L1 runs: w_k = s_k where kappa >= theta or NaN, w_k = 1e-6 + max(kappa,
        0) below theta (always below any bond, Lambda >= 4), so low-cohesion junctions split first and every L1 run stays
        a root; node kept if n >= 2 and Lambda(n, E_closed) >= tau (the bond tau). Why: the three ideas stay (grow by
        bonds, order by cohesion, confirm the whole by tolerant recurrence), the hard cut goes (a cut can never be undone
        by recurrence, so L4 can never report more than an L2 piece), and the whole is tested at one threshold shared
        with its parts, with the E estimator that has no 1/3-group resolution floor, because the node null was empty.
L4b+    every node of the L4b tree.
Cost    DPANN group build (bonds in 4 corpora, 4 thetas, recurrence of 1,032,127 node intervals = 204,645 family-set keys
        in 4 corpora) 141 s on 24 threads, 1.6 GB; L4b 68 s; Spacedust 116 s / 60 s; word ladder (28 runs) 160 s.

FAILURE ANALYSIS
- A cohesion cut deletes real loci. kappa scores how consistent the neighbours of a gene's homologs are; in DefenseFinder
  systems on DPANN and in biosynthetic regions spread over 1,317 phylogenetically distant Spacedust genomes the homologs'
  neighbours vary, so kappa is low inside true loci (Spacedust: 81% of all boundaries below .1, L2 at .1 keeps 19.6% of
  genes against 51.2% bonded). Joining by cohesion (the words' phrases) is safe because it only adds; cutting by it
  removes. L4b uses it only to order splits.
- The node null is uninformative because bonds are already null-controlled at the word runs' tau: shuffled genomes keep
  9-14 significant pairs on DPANN (418-465 on Spacedust), so any node-level FDR is far below 1% at delta = tau_node = 0.
- Nesting buys ribosomal resolution and costs excess through the control: L4b+ vs L1 on DPANN +562 resolved, on
  Spacedust control +.044 for +.020 F1. The scorer's largest-overlap-then-shortest rule rewards a nested output only when
  a run-sized node exists inside the over-extended parent; L4b's tree supplies it for 1,598 runs.
- The 56 remaining under-covered runs carry a gap in the bonds inside the run (no significant pair spans some boundary:
  three consecutive background genes or lineage-confined families break the chain). The tree cannot join across a
  boundary with no bond.
- CRISPR-Cas F1 stays below DH under group counting (.419 vs .479), as for every group-counted word output; syn bonds lift
  it to .441 (L4b) and .473 (L3).
