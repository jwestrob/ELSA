AKSHA BUG (separate from the attestation)
On an unattested GPU environment the runtime should route candidates to the exact CPU path; instead it aborts.
sequence_batch_postfilter_candidates_many_impl (native/cuda/ssv_cuda.cu ~4619-4642) returns early with every candidate
marked CPU_REQUIRED before it creates batch->postfilter_workspace (~4791), and plan7_ssv_sequence_batch_compact_
postfilter_f2 (~4939) then fails: "RuntimeError: post-filter workspace is unavailable" (raised from _native.pyx
_forward_profile_selection_raw, line 8347). Every GPU search on this cluster hits it until the environment is attested.
