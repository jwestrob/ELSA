THEIR METHOD AS VERIFIED
Sources: paper full text from Europe PMC (PMC13639185; the OUP page is behind Cloudflare) and the supplementary docx;
code gitlab.pasteur.fr/mdm-lab/papers/bacterial-genome-syntons, commit 84baf1438f13fb6e03dabb8536e4f4dbfc03caa0
(2026-05-23, "Fix window size and add warning"); Zenodo 10.5281/zenodo.21099310 (published 2026-07-01).
  Data        32,791 complete genomes from refseq/bacteria, May 2023, 123 M genes, gembase ids
              (SPEC###.0523.#####.###C_#####).
  Families    MMseqs2 linclust "iteratively" at 99 / 95 / 80 / 50% identity; fam50 drives syntons, fam95 only CRE.
              Coverage, E-value and MMseqs2 version are not stated; no clustering code is published.
  Context     per gene, the unordered set of fam50s at offsets 13..24 on each side (code: 12 < |offset| <= 24), on
              replicons with >= 48 genes only. Genes with identical +-24 arrays form a "cid"; Jaccard between cid sets
              within a fam50; edges at J >= 0.15; single-linkage components = context clusters; representative = the
              lexicographically smallest gene id.
  Count       k_obs(A,B) = adjacency rows (representative of a context cluster of A, gene of B at +-1). Only the
              representative's own neighbours are examined; B on both sides counts 2; A->B and B->A are separate
              tests; only pairs with k_obs > 1 are tested.
  Expectation lambda(A,B) = sum over representatives g of A of 2 nB_r(g) / L_r(g) (replicons >= 48 genes).
  Test        right-tailed Poisson (scipy sf), Benjamini-Hochberg (statsmodels) over tested pairs; score =
              log2((k + 1e-12)/(lambda + 1e-12)) x -log10(q + 1e-12).
  Threshold   paper: q < 1e-5 AND score > 80; code: score > 80 only. Removed nothing in any run here or in their ST2.
  Loci        gene graph, edge between a gene of A and a gene of B within +-2 positions on one replicon (any replicon,
              including < 48 genes) when (A,B) passed; syntons = networkx connected components (one-gene holes
              possible). Synton families = identical sorted fam50 multiset.
  Run time    "a few hours on 40 CPUs" for the 32,791 genomes.
  Validation  share of DefenseFinder v2.0.2 multi-gene instances wholly inside one synton, per subtype; no random-
              placement control or false-positive estimate.
What the second-hand summary got right: Poisson right tail against an abundance expectation with lambda = 2 sum nB/L,
BH, a combined log2 FE x -log10 q score, Jaccard-clustered contexts as the counting unit, linclust families at several
identities, connected-component syntons with one intervening gene, 32,791 genomes. What it missed or got loose: the
context is the far flank (13..24 genes away; the nearest 12 are excluded so that operons up to ~12 genes stay
detectable); replicons < 48 genes are dropped from contexts and lambda (code only); the counting unit is one
representative gene per context cluster, and adjacency is checked on that gene alone; only k_obs > 1 pairs enter BH;
significance is tested on immediate adjacency while links reach +-2; the paper's q < 1e-5 is absent from the code; the
paper says "12 to 24" where the code uses 13..24.

CAVEATS
- The score > 80 threshold is an absolute number tuned on 32,791 genomes ("typically >= 3 contexts"). On Spacedust 95%
  of tested pairs already have q < 1e-5, so the threshold behaves; on DPANN it removes nearly everything (answer 5).
  It was kept, as predeclared; a q-only reading (3,091 / 13,224 DPANN pairs) was counted, not scored.
- The faithful family step is my reconstruction of an unpublished step (linclust cascade with default coverage). A
  more sensitive clustering at the same 50% identity was not run, so the faithful-matched gap mixes the threshold and
  the algorithm.
- The engine reference is the union of 42 readings and native Spacedust the union of 1.64 M blocks; each synton run and
  P2 V-coh0.1 is one reading. The random-placement control absorbs part of that advantage.
- transfer_spacedust's P1 was not written when this report was finalized; the word comparison uses its P2 primary
  (V-coh0.1) and, as context, its CC1 / CC2 secondary rows. Their numbers are theirs; I read them, read-only.
- RefSeq universe: a superset (34,719 assemblies against 32,791), current RefSeq annotations (re-annotated since May
  2023; 131.4 M protein genes here, while their ST1 lists 123.1 M genes on replicons >= 48 genes), 8 candidates without
  a feature table. The 25,747 confident code -> assembly calls rest on singleton context clusters; 7,044 of 32,791
  genomes remain open (4,977 codes without a singleton context, 1,010 whose singleton WPs are all carried by > 20
  candidates, 1,057 tied or below 95%) and need another key (gene-order fingerprints) before the cohort is exact.
- Post hoc diagnostics (family coverage of gold genes, score distributions, replicon lengths) explain results; none
  selected any configuration.
