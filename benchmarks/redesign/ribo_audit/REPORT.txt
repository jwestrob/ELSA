1. THE DEFINITION AS IMPLEMENTED (ribosomal_check.py, blib.ribo_* helpers, vscore Ctx.table)
- Marker: a gene with any Pfam hit (annotations.source = 'pfam', ws_dpann/input/sharur.duckdb) whose name matches
  '^ribosom(al)?_' case-insensitively; 96 names (includes Ribosom_S12_S23, Ribosomal_60s, Ribosomal_S30AE, ribosomal_L24);
  177,848 marked genes, all mapped to the universe.
- Run: maximal set of marked genes on one contig whose consecutive members are <= 3 positions apart (<= 2 unmarked genes
  between). The span runs from the first to the last marked gene and includes the gap genes. The primary set keeps runs
  with >= 16 MARKED genes (the brief's ">= 16 genes" is >= 16 marked genes); spans are 17-45 genes, median 24.
- 1,686 runs in 1,686 genomes; no genome holds two. "114 in Parvarchaeaceae" is counted as genomes by the check and
  equals 114 runs.
- Best locus: the single locus of the output with the largest overlap with the span (ties: the shorter, then the
  earlier start). Recovered: overlap / span >= 0.5 (equivalent to any locus >= 50%).
- Resolved: overlap / span >= 0.8 AND overlap / best-locus length >= 0.8, on the BEST locus only. The brief's wording
  ("one locus covers ... and 80% of that locus lies inside") reads as any locus; the code differs, and the difference
  is the scoring-rule category below (78 / 13 / 126 runs).
- Gap genes count as run genes in both coverage and precision; every gene of the locus counts in the precision
  denominator. Positions are universe gene indices (position_index = gid - contig first gid; no genes dropped).
- Loci are the stored tables; single-gene loci are absent (Ctx.table keeps e > s). In nested readings every locus,
  parent or child, competes for "best".

2. RUBRIC (predeclared.json) AND THE TWO POST HOC VARIANTS
Cumulative states, first state that resolves gives the label: S0b any locus resolves (DEF_SCORING); S1 nearby
Ribosomal_* genes within 5 unmarked genes admissible for precision (DEF_NEARBY_RIBO); S2 OTHER-KIND members removed
from the recall target (DEF_OTHER_KIND); S3 flank genes of run-associated families admissible, <= 2-gene bridges, <= 10
genes (DEF_ASSOC_FLANK); data check at the failure point (DATA_CONTIG_EDGE, DATA_GENE_CALL); S4 run cut at junctions
that recur in no other group (DEF_JUNCTION); otherwise METHOD_SPLIT / METHOD_UNCOVERED (coverage) or METHOD_EXTENSION.
Association (A): family within 10 genes outside a run, n' = groups other than the case's own (642 lineage-free
groups, emb_hom_average_t0.75), E' = expected groups under random placement within each genome, run-associated iff
n' >= 3 and Lambda = n ln(n/E) - n + E >= 10 nats. Junction recurrence (C): family pair within 3 positions, same
statistic over all genomes; a break needs no recurrent crossing pair and >= 1 testable pair (both families in >= 10
other groups).
POST HOC corrected (C): OTHER-KIND = family carries Ribosomal_* domains on < 50% of its members, or length > 2x the
median of its top marker. POST HOC strict (X): C, and marked genes admissible only when run-associated (S1 off).

5. SCORING-RULE CASES
TOK 78 / WCP 13 / EMB 126 runs hold a locus with >= 80% of the run and >= 80% of itself inside, while a larger-overlap
locus is chosen. In every sampled case (TOK 19, EMB 9, WCP 1) the resolving locus lies nested inside the chosen one.
TOK parents: precision median .622 (q10 .367); in 50 of 78 they extend past the run-associated flank, so TOK's
parent loci are over-extended and its children are right. EMB: 99 of 126 would also pass the strict chain (parents
extend into associated flank). Random windows show the cost of any-locus scoring: TOK chance 7.96% -> 10.16% (TOK has
loci of every size), EMB 1.39 -> 1.42%, WCP 0.04 -> 0.04%. Keeping largest-overlap scoring and counting these as
nested-output behaviour is the conservative reading; the brief's own wording reads as any locus.

How to read the categories from the diagrams:
  DEF_SCORING       the chosen best locus [ ] spans the run plus a long flank (prec .27-.77); a child locus inside it
                    fits the run (listed in results/cases.tsv loci_rel).
  DEF_NEARBY_RIBO   the locus covers the run and a second Ribosomal_* cluster (M) 3-5 genes away. In Iainarchaeota
                    this cluster is S6e / L24e / S28e / L7Ae with IF-2, dUTPase and NDK between; under the strict
                    ruling these TOK cases are method errors.
  DEF_ASSOC_FLANK   bf 1.0 with 5-10 extra genes, almost all a (SecY, EMC3_TMCO1, L34e, primase, helicase).
  DEF_JUNCTION      '/' marks junctions adjacent in no other group; in Aenigmatarchaeota the strand line flips at the
                    junction (two superoperon halves transcribed apart, 1-2 genes between); every output cuts there.
  METHOD_SPLIT      cuts at junctions that recur widely (Iainarchaeota L34e|neighbour, L5|S14; Nanobdellota L29|S3).
  METHOD_EXTENSION  the locus runs 8-110 genes into o genes beyond the run-associated flank.

11. LOW-CONFIDENCE AND UNCLASSIFIED CASES
No sampled case fell outside the rubric. Three carry low confidence:
  U-WCP-27 (run 5279, Nanobdellota) DATA_GENE_CALL: the best locus ends at L6; the next two genes are fragments of one
    family (60 + 130 aa, no Pfam hit) where L32e is expected, then L19e. A split ORF at the cut; plausible cause.
  U-EMB-07 (run 5132, Iainarchaeota) DATA_GENE_CALL: L32e is split (162 + 49 aa, one family) at positions 17-18 and S14
    is absent between L5 and S8, where EMB cuts. Gene-call trouble on both counts; the rule fires on the L32e pair.
  U-EMB-31 (run 5682, Nanobdellota) predeclared DATA_CONTIG_EDGE, corrected METHOD_SPLIT: EMB cuts the run into three
    loci with the remainder toward the contig end; the edge rule fires on geometry, and causation by the edge is
    unshown.
The predeclared DEF_OTHER_KIND label is wrong in premise for every case it covers except the length-flagged ones
(listed per case in results/cases.tsv: other_kind_members); those cases carry their corrected label throughout.

12. CAVEATS
- The headline uses a post hoc correction of one evidence rule; the predeclared numbers are reported beside it.
- Association is measured on family tokens (MMseqs2 rescue3) and 642 lineage-free groups; lineage-confined families
  score as unassociated, so the strict ruling leans toward calling extensions method errors.
- S1 / S3 admit up to 2 unassociated bridge genes and, in the corrected chain, the genes between nearby Ribosomal_*
  genes; the strict chain admits associated genes only (bridges kept).
- DEF_JUNCTION takes the piece with the largest overlap with the best locus as the target, which favours the output;
  the proposed definition inherits this (14-21 runs per output).
- TOK's loci table holds 650,438 loci of every size; its chance level (8% of random windows resolved) is 6-200x that of
  WCP and EMB, so resolved counts compare outputs with different chance floors.
- Near-identical genomes appear as near-identical cases (e.g. U-WCP-36 / U-WCP-37); the sample is of runs, not of
  lineages.
- Login-node work only (one thread): repro 24 s, stats 8 s, census + random windows 98 s, cases 39 s, full 30 s.
  No Slurm job was needed.
