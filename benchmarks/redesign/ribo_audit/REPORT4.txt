ribo_audit PART 4: the cluster-level ribosomal run definition, frozen, on the lut test set and DPANN
written 2026-11-19 ~10:15Z; predeclared4.json written 09:06Z before any lut or DPANN run, locus or annotation was opened under the
new definition. The definition was written POST HOC on SR-VP (part 3). lut and DPANN are a check of the definition on data it was
not developed on, with method outputs frozen earlier. DPANN caveat: its runs were audited under the standing definition in
parts 1-2, and the archaeal member list was compiled for it in part 2.

ANSWER
1. On lut (858 runs, all Bacteria, never opened before) the definition holds up. Resolved goes from standing to cluster level:
   embedding-list tree (Z) 811 -> 835, family-bond adaptive tree (WA) 788 -> 822, engine DH 668 -> 768. Chance is 2.1-2.9%.
   Definition-attributable verdicts (2 and 3) fall from 36 to 18 (Z) and from 39 to 29 (WA). All three predeclared criteria are met.
2. On DPANN (1,686 runs, all Archaea) it fails all three criteria. Resolved goes Z 1,542 -> 1,491, WA 1,594 -> 1,522,
   DH 1,512 -> 1,443. Verdicts 2 + 3 rise from 51 to 99 (Z) and from 33 to 101 (WA). Chance is 4.4 / 4.9 / 7.0%
   (standing 4.6 / 5.1 / 6.2%); DH is above the 5% bar under both definitions.
3. The cause is strand-blind chaining. 66 of the 84 runs Z loses gain opposite-strand genes. In 53 of them the chain adds secY
   plus the divergent block EMC3_TMCO1-Nre_N-cbf5: cbf5 is on the archaeal member list and the two genes before it fit the
   <= 2-gene gap. Z stops at the strand change, which is where the accurate locus ends. 54 of the 84 lost runs are verdict 3:
   Z's locus equals the accurate locus and the target is 3 genes longer. The domain-specific reading changes nothing
   (Z 1,491, WA 1,522, DH 1,444).
4. lut's 94.5% standing resolution comes from short spc-alpha inserts. 75.1% of lut runs carry secY-adk (2 unmarked genes),
   which puts the alpha block inside the run; the median insert is 2. SR-VP Bacteria have a median insert of 4
   (secY-adk-map-infA in 43.9% of runs). SR-VP's class rates reweighted to lut's insert distribution give 91.4% (Z) and 91.3%
   (WA), against lut 94.5% / 91.8% and SR-VP 59.3% / 57.4%. So insert size explains 32 of the 35-point gap for Z and 34 of the
   34-point gap for WA. The predeclared test still says NO: in the >= 3 class lut resolves 66.7% and SR-VP 40.4% (Z),
   a 26-point gap.
5. The cluster-level definition is sound for Bacteria (SR-VP development data, lut check) and unsound for Archaea as frozen.
   For Archaea the standing run is the better benchmark: on DPANN it resolves more for every output, and the cluster target
   there joins divergent neighbours. A strand-aware chain is the evident repair; it is untested here and would need a fresh check set.

1. WHAT WAS FROZEN (predeclared4.json) AND THE CODE CHECK
  The definition is exactly as run in part 3 (bio3.py cmd_extdef with the Bio3 annotation merge):
  - Marker classes:
    - R = package Pfam ribosomal marker, or the best of 226 searched KOs whose definition contains 'ribosomal protein'.
    - N = part-2 archaeal list (N_RULES, 25 KOs and 20 Pfam models with the EF2 rule) plus the 16-KO bacterial supplement.
  - Chain: R + N genes with <= 2 other genes between them; strand and spacing are ignored.
  - Target: the chain containing the package g2_m16 run.
  - Scoring is the standing rule. Recovered: best locus covers >= 50%. Resolved: best locus by largest overlap (ties to the
    shorter) covers >= 80% with precision >= 0.8. Any fitting locus is counted with the same 80 / 80 test.
  - Chance: 5 random same-contig windows per run of the target length, seed 17.
  Found while freezing: part 3 applied BOTH member lists to EVERY genome; domain only stratified the results. That union is the
  PRIMARY reading here. The requested domain-specific reading (Archaea genomes: archaeal list only) is reported beside it.
  Code check: bio4.py reproduces part-3 extdef.json exactly on SR-VP (resolved and chance in every cell) and the part-3
  standing verdicts for Z and WA in every cell.

7. WHAT ARGUES AGAINST THE DEFINITION
  - Strand blindness. It costs DPANN 84 / 94 / 111 resolved runs against 33 / 22 / 42 gained. The chain also glues units across
    opposite-strand genes in Bacteria: verdict-2 cases with a strand change are 36 of 74 on lut and 25 of 44 on SR-VP
    (all outputs).
  - The archaeal list contains cbf5. Its divergent position 2 genes past secY puts it in the target of 53 lost DPANN runs. A
    member list built for literature membership is used here as a chaining signal, and the two jobs differ.
  - It narrows the engine gap. Z minus DH resolved is 143 standing vs 67 cluster on lut, and 199 vs 71 on SR-VP Bacteria,
    because DH reports whole clusters more often. The outputs still lead on every dataset where the definition holds.
  - Chance on DPANN is 4.4-7.0% under the cluster definition and 4.6-6.2% under the standing one, so it is a property of the
    dataset rather than of the definition. It exceeds the 5% bar for DH under both.
