ANSWER IN EIGHT LINES
1. No round-2A output matches token DH; CRISPR-Cas F1 blocks every one. The predeclared together run (context N_eff vec
   W25 + token classes .67, cohesion phrases) gives summed .572, +0.145 [+0.119, +0.171], F1 .730/.610/.405 (CCT -0.075
   [-0.087, -0.062]), ribosomal 1,672 / 1,470, Parvarchaeaceae 114. The best output is simpler: stage-1 words + cohesion
   phrases, +0.181 [+0.158, +0.204], F1 .735/.636/.395, ribosomal 1,684 / 1,420, Parvarchaeaceae 114 / 109: every
   "matches" bar except CRISPR-Cas (-0.085 [-0.096, -0.073]).
2. The ribosomal failure is solved by a phrase level, not by classes. Joining consecutive words where ws_context's
   token cohesion >= 0.1 (theta chosen on odd) lifts resolved runs from 501 to 1,420 on the stage-1 vocabulary. Token
   classes add -0.003 [-0.007, +0.001] on top. At the word level classes nearly double resolution (501 -> 964); under the
   selected reading they give 1,437, so the predeclared refuter (< 1,000) does not fire.
3. Context N_eff: the coordinator's prediction is refuted (CCT .406 with summed .576; bar .47 / .55). tau* = 10 in all
   four context arms (FDR at 8: 1.3-1.5%). Measuring context outside the span at merge time relaxes the unit-size discount
   as words grow (ribosomal words N_eff/n .03 in round 0 -> .43-.52 at 23-26 genes), but seed pairs inside conserved
   units stay discounted 30-90x. Shuffled contexts reproduce the genome unit (CCT .497 vs .504; -0.197 summed).
4. Synteny-retention N_eff (no window, no threshold; tau* = 8) gives the best CRISPR-Cas of any vocabulary: F1 .452,
   -0.027 [-0.038, -0.015] vs DH, with DefenseFinder +0.025 and TXSScan +0.154. 37.6% of Cas member genes stay outside
   every word (groups: 45.5%). It costs -0.050 [-0.066, -0.034] summed against the 642-group arm. It has no unit-size
   confound at the word level: 82 Parvarchaeaceae ribosomal runs recovered, against 11 with groups.
5. CRISPR-Cas does not come back through broader identity at the word level, because word classes act only on words
   that already exist. At the selected theta they leave Cas coverage unchanged (45.3-45.4% of members outside words vs
   45.5%). Loose vector classes (theta .6, post hoc) pool Cas words across subtypes (766 instances in mixed-subtype
   classes, median group gain 1.68x) and add only 25 Cas instances. Identity has to be broadened at the unit level,
   before the first merge.
6. Description length rejects classes: D rises monotonically with theta (token .34 -> .67: 240k -> 402k nats; vector
   .6 -> .9: 129k -> 428k), so the gold-free rule picks the most conservative classes. Typing barely moves: DefenseFinder
   AMI .473 vs .464 exact, homogeneity .99, completeness .42; engine modules .779.
7. Search by parsing (2,447 DefenseFinder queries): MAP .098-.108 for every selected vocabulary at labelled precision
   .99 (0.10-0.16 wrong hits per query); loose vector classes (post hoc) .317 at .98. Whitened ranks give .796, MMseqs2
   .610, tokens .369. A vocabulary is a high-precision, low-recall retriever.
8. Adopt stage-1 words + cohesion phrases as the token-route output. Synteny retention is the independence measure
   that recovers CRISPR-Cas; with cohesion phrases it reaches CCT .430 and resolved 1,326, so the two levers still
   compete. Close CRISPR-Cas by broadening identity at the unit level (family classes or family-free units before the
   first merge), and test synteny retention on that alphabet.

4. INDEPENDENCE FROM CONTEXT (part 1)
  Definition as ws_context (window of +-W genes outside the instance span, per-genome pooling, c0 / sd0 floor, z = 2,
  Kish N_eff), with the span taken at the moment the merge is tested, so a growing word looks past its own genes.
  Lambda_eff = Lambda_genome x N_eff / n; rules n >= 2, N_eff >= 2, Lambda_eff >= tau.
  Unit-size diagnostic (results2a/diag2a_unitsize_*.json; committed words, f = N_eff / n by merge round):
    vec W50 ribosomal words (241): .033 / .120 / .109 / .243 / .435 / .522 (rounds 0-5; median span 3 -> 26 genes)
            other words (34,348):  .495 / .514 / .599 / .665 / .664 / .701
    vec W25 ribosomal (267):       .011 / .039 / .035 / .221 / .444 / .413; other .480 -> .675
  Growing spans remove most of the discount once a word covers the conserved unit, but the round-0 seed pairs inside it
  are discounted 30-90x and only 14-18 commit. Committed words sit at N_eff median 3.4-3.7 in every stratum (selection at
  the N_eff >= 2 / Lambda_eff >= tau bar). Vector contexts discount more than token contexts (32.6 k vs 53.8 k types);
  token contexts keep CRISPR-Cas better (tok W50 V-mob odd CCT .470, the only vocabulary to meet the odd F1 condition) and
  lose summed excess (odd .538).
  Control: contexts shuffled among occurrences give the genome arm back (152,192 vs 152,528 types at tau 10; V-mob CCT
  .497 vs .504), so the effect lives in the real contexts.

5. INDEPENDENCE FROM SYNTENY RETENTION (amendment_1, point 2)
  S(g, h) = share of g's round-0 adjacent token pairs also adjacent in h, symmetrised, S(g, g) = 1; N_eff = n^2 / sum over
  carrier genomes g, h of S(g, h) (exact). Inherited order is measured directly in the units of the test; a conserved
  unit contributes only its own share of each genome pair's adjacencies, so unit size does not enter.
  Result: tau* 8; CRISPR-Cas F1 .452 (the best of any vocabulary; dF1 -.027 vs DH), DefenseFinder .769, TXSScan .702; Cas
  members outside words .376; summed -.050 vs groups, +.154 vs every-genome units; ribosomal at the word level 1,184 / 510
  with Parvarchaeaceae 82 / 68 recovered / resolved (groups 11 / 9); with cohesion phrases 1,685 / 1,326 and CCT .430.
  Unrelated genomes share a median 2.9% of adjacencies (q99 22%), so a widespread pair saturates near N_eff ~ 1 / S-bar.

7. COHESION PHRASES (amendment_1, point 3)

  6 of 9 vocabularies (.05 once). On the stage-1 vocabulary: resolved 501 -> 1,420, Parvarchaeaceae recovered 11 -> 114,

  (V-phr) resolve 1,168: cohesion separates conserved neighbourhoods from chance adjacency better than recurrence counts
  do.

CAVEATS
- Timestamps in the stage-1 NOTEBOOK.txt after ~02:30 and the first round-2A entries were estimates running 20-40 min
  ahead of the clock; NOTEBOOK2A.txt lists corrected times from sacct and file mtimes. The order of events is unaffected.
- The vector context arms were first scored on odd with the original reading pool (job 88872, outputs 03:43-03:45, read
  after amendment_1 was saved at 03:44); all were rescored with the amended pool (job 88943) before selection.
- The class theta rule (D) selects the edge of each ladder; looser classes than the ladder's lowest theta were not run,
  and the description-length charge for a class member (tau per follower composition) is a modelling choice made before
  any full-data class run (NOTEBOOK2A 03:23-03:26).
- Cohesion comes from ws_context's array (token families + zca10 vectors); V-coh therefore reads one external,
  landscape-independent array; theta was chosen on odd genomes per vocabulary.
- Search AP is computed on an unranked set (ties averaged), so it is not directly comparable with ranked AP; the
  parse finds a word for 84-88% of queries and the rest score 0.
- Vector .6 classes are post hoc in every table where they appear (not selected by the predeclared rule).
