2026-11-13 02:10  Design (written before any computation).
  Objective. A word is a node of a merge tree over symbols (terminal = family token). The corpus that is compressed is
  the group-level occurrence record: one group (lineage unit) contributes at most one occurrence of an adjacency, so
  shared descent is not paid for twice. For two live symbols X, Y adjacent (<= 2 intervening single genes, unordered,
  X != Y), n = groups with an occurrence, E = expected groups under random order within each genome:
     E = sum_groups [1 - prod_{g in group} (1 - min(1, 2 w c_X(g) c_Y(g) / m_g))],  w = 3, c = live copies, m = live nodes.
  Gain Lambda = n ln(n/E) - n + E (nats): the code-length saving when the n group occurrences are described as instances of
  one word (rate fitted) instead of chance co-placements (rate E). This is the Poisson log-likelihood ratio, so the MDL
  merge criterion and the engine's significance test are one quantity; the cost of naming a rule (~2 ln S nats) is what
  the null calibrates.
  Updates. Rounds. Each round: enumerate adjacencies among live nodes; Lambda per symbol pair; candidates n >= 2 and
  Lambda >= tau, applied in decreasing Lambda; an occurrence claims its two nodes plus the single genes between them (order:
  distance, then position); a pair is committed only if its claimed occurrences still give n >= 2 and Lambda >= tau; each
  committed pair becomes a new symbol and its occurrences become one node. Repeat until nothing commits.
  Output: every gene is a slot of one top-level word instance, an inserted gene inside one, or background.
  Stop: the identical procedure on genome-shuffled tokens (engine null); tau = smallest ladder value whose word-type FDR
  (null types / observed types, mean of 3 shuffles) <= 0.01. No other threshold.
  Readings: V-top = top-level instances (single); V-nest = V-top + children that are words; V-mob = V-top + maximal
  sub-instances whose type is also top-level in >= 2 groups (mobile units: unit identity from context).
