SOFTREC WORKSTREAM: TOKEN-FREE RECURRENCE FROM RANKED NEIGHBOUR LISTS (DPANN, 2026-11-12)
==========================================================================================

QUESTION
Jacob asked whether properly whitened embeddings had been tested for discovery. Until now they had entered only as
hard families (Leiden communities of the zca10 kNN graph, used as engine tokens). Here the same whitened vectors
enter discovery as graded evidence: each gene's ranked neighbour list replaces its family token. The token engine is
the special case in which a gene's list is its family.

ANSWER IN EIGHT LINES
1. Predeclared outcome: neither MATCHES nor BEATS. The selected variant (zca10, top 1,000 genes outside the genus, count
   rule L >= 15) raises the summed DefenseFinder + TXSScan excess on held-out even genomes by +0.061 [+0.041, +0.080]
   (enough for "beats"), but TXSScan F1 is 0.699 against 0.758 (-0.059; the bars were -0.02 and -0.01).
2. It is the first single-input (embedding-only) discovery arm that is both above the base and admissible: ribosomal
   check 1,681 / 1,686 runs, 114 / 114 Parvarchaeaceae, 984 runs resolved (base 711). Hard zca10 families above the base
   lost the locus (V0 r19000: +0.038, 1,155 runs, 6 / 114).
3. At the engine's default single reading (conserved@2) softrec beats the token engine: +0.054 [+0.032, +0.075] summed
   excess, DefenseFinder F1 +0.038, TXSScan F1 +0.036, CRISPRCasTyper -0.009 [-0.020, +0.002] (even genomes).
4. The full-table TXSScan loss sits in the locus reading: the unit reading (TXSScan F1 0.655 vs 0.722) and four
   missing intermediate readings (rule L >= 15 leaves no support between 2 and 14 genera, so 7 distinct readings vs 11).
5. The CRISPRCasTyper loss (F1 0.499 vs 0.589) sits in the statistic: at depth 1,000 chance support forces L >= 15, and
   variable Cas pairs fall below it (CRISPR-Cas member genes touching support 0.616 vs 0.765).
6. The kernel reproduces the token engine exactly when the list is the family: all 9,350,064 instances have the
   engine's L and G, and all 2,939,492 loci of the 11 readings equal the v5 base.
7. The machinery alone (counting G and E over other genera, family lists) gives +0.011 / +0.014 at unchanged TXSScan
   F1; the embedding lists add about +0.05 on top, through DefenseFinder localization (DF excess +0.071, TXSS -0.011).
8. Depth-50 count variants gain the most (+0.064 to +0.068 test) and are inadmissible (97-101 / 114 Parvarchaeaceae);
   the Poisson statistic, which makes whole families usable, fails with deep lists (-0.066 to -0.104 tune).

DESIGN (predeclared.json, 13:27 UTC, before any job; amended by the coordinator's 14:05 request, see section 5)
- Instance: every gene pair (a, b) within 3 positions on one contig (9,399,310). Homologous pairs excluded as the engine
  excludes ta == tb (family lists: same token, 49,246; embedding lists: identical sequence or cosine(a, b) >= max(0.32,
  the cosine at which b would enter a's list or a b's), 56,037 at depth 50 to 163,435 at depth 1,000).
- List N(a): ranked genes outside a's genus (own-genus genes can never add a lineage; Parvarchaeum alone has 190
  genomes). Embedding lists: unique-sequence HNSW top-2000 (M 32, efC 200, efSearch 2001; recall vs exact on 2,000
  queries: zca10 0.999 / 0.999 / 0.994 at 50 / 200 / 1,000; head 0.999 / 0.999 / 0.995), identical sequences first,
  ties share the tail rank, cut at depth K (50, 200, 1,000 genes) and cosine floor f (none, 0.4).
- Statistic per instance: L_o = genera other than a's genus with a pair (a', b') within 3 genes on one contig,
  a' in N(a), b' in N(b), a' != b'; G_o genomes; E_o = sum_G min(1, 2w c_a c_b / n_G); graded S = sum over genera of the
  best pair's min(log(N_db / tail rank)). Engine convention L = L_o + 1, G = G_o + 1, P = Poisson(X >= G | E).
- Null: gene order shuffled within each genome (contig sizes kept), RNG seeds 1000-1002 exactly as the engine
  (verified: same permutations); instances and target co-location both recomputed on the shuffled order.
- Rules per statistic family: count L >= m; poisson P <= 1e-e & L >= 2|3; graded S >= t. The engine's selection at the
  instance level: FDR (mean null instances / observed instances) <= 0.01, top 12 by count, most genes covered.
- Loci: the engine's 11 readings (conserved and conserved_g2 at 2 / 5 / 12 / 30 / 80 genera, unit@0.5 on the genome
  sets of the best instance per boundary), module_id -1 (no tokens, no modules).
- Selection: highest odd-genome summed excess vs the base among admissible pool variants (ribosomal >= 1,650 runs and
  >= 110 / 114 Parvarchaeaceae). Pool: zca10 and head lists x 3 depths x 2 floors x 3 statistics, plus the first
  end-to-end zca10_k50 (stored top-50 unique kNN); 42 results, 30 admissible.
- Criteria on even genomes vs base (DF F1 .806, TXSS .758, summed .447): matches = summed >= -0.01 with DF and TXSS F1
  each >= base - 0.02; beats = summed >= +0.02 (interval above 0) with neither F1 below base by > 0.01.

6. WHICH PART FAILS (predeclared attribution)
  - Machinery: no. The kernel and locus reading reproduce the engine exactly (section 1); instance-level selection costs
    0.007-0.014; lineage-aware G/E gains 0.011-0.014.
  - Null: no. Rule L >= 15 holds instance FDR 0.0046; the threshold is high because chance support is real at depth
    1,000 (null L >= 2 instances 7.8 M vs 7.1 M observed).
  - Statistic (CRISPR-Cas): yes. The count threshold that the deep-list null forces (L >= 15) removes variable Cas pairs:
    CRISPR-Cas member genes touching a supported boundary 0.616 vs 0.765, covered50 0.782 vs 0.884.
  - Locus reading (TXSScan): yes. TXSScan members keep support (0.951 vs 0.979 touch a supported boundary) and the
    default reading is better (+0.036 F1), but localization falls (0.795 vs 0.947). Per reading, TXSScan F1 softrec /
    token (share of instances whose full-table best it reaches): conserved@2 .448 / .412 (.18 / .11), conserved@80
    .347 / .355, conserved_g2@80 .334 / .373, unit@0.5 .655 / .722 (.69 / .77); levels 5 and 12 absent in softrec.
  Unit mechanism (exploratory, head K1000 f0.4 graded, job 82007 / 82194; tune TXSS F1 by unit Jaccard): 0.3 .627,
    0.5 .691, 0.7 .708, 0.85 .706; genus-level profiles .674 (test TXSS F1 .631 / .710 / .724 / .721; genus .691).
    Softrec units are over-merged: a bounded list is filled by the genome's closest relatives, so every instance in a
    genome draws its supporting genome set from the same relatives and profiles stay alike across system edges; a
    token pair's profile is the pair's own incidence and changes at the edge. Stricter Jaccard recovers +0.017 and
    saturates 0.04 below the base, so the threshold cannot replace pair-specific profiles. (My first reading at 15:20,
    "units fragment", was refuted by the 0.3 run and corrected in the notebook.)

  - zca10 mean and covariance use all 2.5 M sequences, including even genomes (unsupervised, as in the head workstream).

  - The floor 0.4 was set by zca10's cosine scale; in head space it sits near the random-pair q99.9 (0.39).

  - Single-reading and rule-H comparisons were requested after predeclaration; the selection used the full table.
  - Exploratory unit runs (Jaccard, genus profiles) used one head variant; they are diagnostics, not candidates.
