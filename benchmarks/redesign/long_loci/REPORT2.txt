   -.036. With the part-1 rule, A and As keep the filtered L4b; Z and Zs need L4b+ for the CRISPR-Cas bar.
8. Spacedust needs neighbour lists for its 1,317 genomes (section 'SPACEDUST'); the alignment arm can be built on CPU
   alone (MMseqs2 all-against-all, about 16 h on 64 CPUs) with the existing token cohesion array.

FAMILY-FREE NODE FILTER (code/lb.py count_lists; brute-force check on a synthetic universe, 0 / 261 mismatches)
  For node I: |I| = genes of I with a non-empty list; q = max(2, ceil(|I|/2)); W = 2|I|; a genome holds I when a window
  of <= W genes on one contig contains list partners of >= q distinct genes of I, each partner position counted once
  (for the lowest-indexed node gene listing it); n = groups other than the node's own holding I; E = part-1 closed form
  with c_f(g) = partners of node gene f in genome g; kept at n >= 2 and Lambda(n, E) >= the arm's bond tau (6). Kept
  share of tree nodes at theta .02: Z 89.3%, A 89.4%, Zs 86.1%, As 86.4%, FZ 86.6%.

SPACEDUST: WHAT ADDING IT NEEDS
  (1) Lists for 1,317 genomes / 4.26 M genes: z lists need ws_calib's per-genome best-match z table, one all-against-all
      embedding pass (4.23 M unique x 4.26 M genes x 960 d; ~25 min on one GPU, 9-10 h on a 64-core Broadwell node per
      transfer_spacedust's estimate); alignment lists need an MMseqs2 all-against-all of 4.23 M unique sequences (-s 7.5,
      --max-seqs 1000; DPANN's 2.55 M took 6.0 h on 64 CPUs, so roughly 16 h) and mm2knn.py.
  (2) Round-0 homolog exclusion masks (vl uses zca10 kNN lists: GPU kNN k 2,000 on the collection) or a rule derived from
      the MMseqs2 hits; (3) family-free cohesion kappa_var_knn50 (top-50 kNN; same kNN) or the existing token array
      $RD/transfer_spacedust/emb/kappa_var_tokens.npy, which on DPANN gave more resolved runs; (4) a vl.Univ variant for
      $RD/universe (lf_universe reads the DPANN package path) with the 618 groups; then lb.py and sscore.py unchanged.
  The alignment arm with token cohesion therefore needs no GPU: about 16 h of MMseqs2 plus 30 min of lb.py and scoring.
