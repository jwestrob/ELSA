THE METHOD BEING CHECKED (unpublished; describe it to no one, just compare it with the literature)
Goal: find conserved gene neighbourhoods (operon-like loci, defence systems, secretion systems, biosynthetic clusters) across thousands of prokaryotic genomes, de novo.
C1. Merge procedure. Each contig is a sequence of genes. Every pair of neighbouring units (up to 2 intervening genes, either order, either strand) is a candidate. A candidate is scored and the best-scoring pairs are merged greedily into a single unit, which can merge again; rounds repeat until nothing passes. The result is a hierarchical parse of each genome into nested "words" (conserved runs of genes) and background genes.
C2. Score. n = number of independent lineages in which the two units are neighbours. E = number of lineages expected to show them as neighbours if gene order within each genome were random, computed from per-genome copy numbers. Score = n ln(n/E) - n + E (the Poisson log-likelihood ratio), read as the description length saved by naming the pair as one word. One threshold, set so that the same procedure run on genomes with gene order shuffled within each genome yields at most 1% as many discoveries.
C3. Independence of evidence. Counting every genome separately lets shared ancestry pass for recurrence. Two corrections: (a) count data-derived genome groups (clusters of genomes by protein similarity, no taxonomy) instead of genomes; (b) an effective count N_eff = n / (1 + (n - 1) * s), where s is the mean, over pairs of genomes carrying the pair, of the fraction of gene adjacencies the two genomes share (a direct measure of inherited gene order), with the score scaled by N_eff / n.
C4. Null model. Shuffling gene order within each genome (contig sizes kept), used both for the expectation E and to calibrate the threshold; the observation that such a null cannot see gene order inherited within a clade.
C5. Benchmarks and validation. Scoring de novo loci against curated system callers (DefenseFinder, TXSScan, CRISPRCasTyper), with a random-placement control subtracted from F1; a ribosomal-protein locus check.
