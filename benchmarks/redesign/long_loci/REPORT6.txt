ANSWER
1. P base (family-bond tree, adaptive distance): the fixes are NOT biologically justified by the predeclared checks.
   - S gains the most accurate loci of any P variant: audit strict 1,592 (+54), loose 1,634 (+63), standing resolved
     1,622 (+28 [+15, +42]), 3 new curated pairs.
   - It costs DefenseFinder F1 -.015 [-.022, -.007] and CRISPR-Cas F1 -.019 [-.025, -.014]. CRISPR-Cas .441 falls
     below the DPANN bar. Verdict: NOT SHOWN.
   - B is UNJUSTIFIED: strict 1,487 (-51), standing -50 [-65, -36]. Every one of the 53 runs it loses is taken by a
     bridged union. The union covers more of the run than the base locus did and so wins the largest-overlap rule, at
     median precision .63. Inside the tree it repairs only 2 of the audit's 23 split runs.
   - SB repairs 21 of the 23 (the audit's count on paper) but loses 54 other runs to over-extended unions: net strict
     +29, standing +5. CRISPR-Cas bar fails. Verdict: NOT SHOWN.
2. Z base (embedding-list tree, fixed distance): the fixes come close to justified but are NOT SHOWN by the predeclared
   criteria. The single failed condition is summed curated excess.
   - SB: strict 1,585 (+81), loose 1,634 (+87), standing 1,624 (+82 [+65, +101]); recovered 1,685; all seven bars met;
     0 new curated pairs; CRISPR-Cas F1 unchanged (.490). Costs: DefenseFinder F1 -.006 [-.010, -.002], TXSScan F1
     -.010, summed excess -.017 [-.025, -.010] against the predeclared -.01.
   - S alone: +60 / +66 / +56 at the same cost.
   - B alone: +2 / +3 / +9, loses no run, changes no curated score.
3. Z carries the fixes better.
   - Its SB variant reaches the highest accurate-reading count of the eight variants (1,585 strict, 1,634 loose).
   - It keeps every DPANN bar, adds no curated pair, leaves CRISPR-Cas untouched, and loses 1 run where it gains 83.
   - P's best variant (S, 1,592 strict) fails the CRISPR-Cas bar, and P's bridges cost runs.
   - The difference is the node rule. Z keeps every node, so a bridged union sits beside its parts. P's family node test
     keeps unions that over-extend, and the largest-overlap scorer then prefers them.
4. Strand-aware splitting is the change that carries the biology. It changes 24.8% (P: 457,709) and 22.4% (Z: 354,209)
   of bonded boundaries genome-wide and supplies most of the accurate-reading gain on both bases. Its cost falls on
   curated systems whose members lie on both strands (TXSScan / DefenseFinder F1 -.003 to -.015). Boundary precision of
   the best locus is unchanged (median 1.0 / 1.0 / .5 for DF / TXSS / CCT in every variant); P's share of genes in loci
   drops from .552 to .533, Z's stays at .571.
5. Bridging rule for the list base, evaluated without families: for each genome of another lineage group, the list
   partners of the two junction genes in that genome (z >= 10.6 lists, one best match per genome, own group excluded)
   must lie in one top-level locus of the frozen Z output; the rule fires when such genomes span >= 3 groups and the
   junction is same-strand with <= 150 nt spacing.
   - DPANN: list rule 5,354 fires (5.5% of 97,162 candidates), family-token rule 5,078; agreement Jaccard .497.
   - Spacedust: 2,130 vs 5,010; Jaccard .257.
   - The firing sets agree only partly, yet the outcomes agree. DPANN B vs Bf and SB vs SBf have identical ribosomal
     counts and summed excess within .0002. Spacedust: +.112 vs +.113 and +.118 vs +.119.
6. Curated-merge check (pairs of distinct curated instances in one locus that no frozen locus held together): P S / SB
   3 (the frozen P holds 45 such pairs), B 0; Z 0 in every variant (frozen 53). Junction-level merges at bridges: 0 on
   both bases.

METHODS AND DEFINITIONS
 Weights: w = s (largest Lambda of a bond spanning the boundary); bonded boundaries with cohesion < theta: 1e-6 +
 max(kappa, 0); S: bonded boundaries with a strand change: 1e-9 (split first; all strand changes of a node split together
 in the tie-collapsed tree); B: bridged junctions (previously unbonded): 1e-8. P keeps nodes with n >= 2, Lambda >= tau
 (6), nI >= 2 (closed-form family test, ll.recurrence); Z keeps every node with >= 2 genes.
 Bridges: computed once per dataset and base from the frozen output (P L4b .2, Z L4b+ .02): candidate = a locus ends at
 k, another starts at k + 1, same contig, no locus spans k|k+1, no bond spans it; (iii) same strand and intergenic
 spacing <= 150 nt (gene coordinates: DPANN package; Spacedust metadata / crosswalk start-end); (i) families: token
 families of both genes in one top-level locus in >= 3 other lineage groups; (i) lists: see ANSWER 5.
 Selection: theta in {.02, .05, .1, .2} on odd genomes by [odd conditions vs DH, odd resolved, odd summed]; applied
 mechanically before the even report (results/p6/score_dpann_*.json, 'selection'). Odd scores: P S [2, 817, .527] vs
 base [3, 806, .522] (S misses the odd CCT condition at every theta); Z SB [3, 820, .570] vs base [3, 781, .591].
 Accurate reading: ribo_audit bio.py imported read-only (Bio, run_units, score_target), strict 150 / 500 nt, loose
 500 / 500 nt. Curated-merge check: member spans of package gold instances (>= 2 members, one contig), pairs inside one
 locus of the variant and inside no locus of the frozen base.
 Criteria (predeclared6.json): JUSTIFIED = strict >= base + 10 and loose >= base, DF / CCT F1 >= base - .01 and
 summed >= base - .01, <= 10 new pairs and 0 junction-level merges, standing >= base - 10; UNJUSTIFIED = > 25 new
 pairs, DF / CCT F1 below base by > .02 with upper bound < 0, strict below base, or bridges at > 10% of candidates.

DEVIATIONS: none from predeclared6.json. Bf / SBf were built and odd-scored at every theta (only the B / SB theta is
reported, as declared).
