1. The shortfall is the run definition. The g2_m16 run follows Pfam-marked ribosomal proteins with <= 2 unmarked genes
   between them, so it stops at L15 where the spc operon continues through secY-adk-map-infA (3-4 unmarked genes) into
   the alpha operon (L36-S13-S11-S4-rpoA-L17). Both outputs report the whole co-linked cluster. Of the 268 unresolved
   bacterial PRIMARY runs: run definition 256 (95.5%; verdict 3 236, verdict 2 20), scorer's choice among nested loci
   5 (1.9%), over-extension into conserved neighbours 3 (1.1%), extension into unrelated genes 1, gene-call data 3,
   rearrangement 0. SECONDARY (280): 269 (96.1%) / 7 (2.5%) / 1 / 1 / 2 / 0. Loose reading: 258 and 270.
2. Rearrangement explains none of it. Measured without the outputs, bacterial marker order is MORE conserved than
   archaeal: adjacent-pair share across other lineage groups median 0.987 (closed and multi-contig) vs 0.975 in
   Archaea, q10 0.916 / 0.946 vs 0.860; all 658 bacterial runs are collinear with one S10-spc core order (421 runs
   carry all 18 core markers, all 421 in that one order) against 141 / 145 archaeal runs (4 rearranged). No verdict-1
   split exists in Bacteria; unresolved runs holding any rare pair: PRIMARY 7 / 268 (resolved runs 109 / 390).
3. Output-independent check (POST HOC): 259 of the 268 unresolved runs (96.6%) have the alpha block <= 12 genes past
   the run on the same contig; runs whose spc-alpha insert is <= 2 genes (alpha block inside the run) resolve 97 / 101
   (PRIMARY), 97 / 101 (SECONDARY), 88 / 101 (engine DH). Closed genomes do worse because their clusters are whole:
   277 of 398 multi-contig runs lie <= 12 genes from a contig end and resolve 227 / 277 (82%); away from contig ends
   multi-contig bins resolve 55 / 121 (45%) and closed genomes 107 / 258 (41%).
4. Contents beyond the run (PRIMARY, closed): 1,478 genes in 140 runs, 711 ribosomal proteins + 756 literature cluster
   members (secY 140, map 139, rpoA 135, infA 128, adk 119, ...) + 11 other, 0 unannotated; past the accurate locus only
   5 runs (49 genes). The conserved stretch around a closed-genome run adds a median 10 genes (q25-q75 3-11); in
   Archaea 1 (0-2).
5. Ribosomal resolution as defined is unsound in Bacteria: it scores the accurate locus as a failure in 236 / 268 runs.
   A sound definition is the cluster-level run (ribosomal proteins + literature cluster members, same <= 2-gene rule;
   POST HOC): Bacteria PRIMARY 651 / 658, SECONDARY 649 / 658, engine DH 580 / 658 (Archaea 140 / 139 / 120 of 145),
   chance 0.15-1.05% for the outputs and 1.9-2.0% for DH. The predeclared accurate-target scoring with the bacterial
   member list gives 626 / 623 / 530 strict and 631 / 626 / 548 loose (chance 0.9-2.7% outputs, 1.9-4.1% DH).

9. A SOUND BACTERIAL DEFINITION, WITH COUNTS
  As defined, ribosomal resolution in Bacteria measures where the Pfam ribosomal chain happens to end, which is inside a
  co-transcribed cluster; an output that reports the accurate locus fails it in 236 / 268 (PRIMARY) and 249 / 280
  (SECONDARY) unresolved runs. Two definitions measure the intended thing:
  (i) Cluster-level run (POST HOC): markers = ribosomal proteins + literature cluster members (base N list +
      supplement 1), same <= 2-gene gap rule, the extended run containing each original run as target, standard 80 / 80
      best locus. Chance = 5 random windows of the extended-run length per target, seed 17.
                 Bacteria          closed     multi      Archaea    chance closed / multi / Archaea
      PRIMARY    651 / 658         255 / 260  396 / 398  140 / 145  0.15% / 0.22% / 0.70%
      SECONDARY  649 / 658         257 / 260  392 / 398  139 / 145  0.23% / 0.33% / 1.05%
      ENGINE DH  580 / 658         210 / 260  370 / 398  120 / 145  2.00% / 1.89% / 1.93%
  (ii) Accurate-target scoring (predeclared; section 4): PRIMARY 626, SECONDARY 623, DH 530 of 658 strict.
  (i) is the simpler replacement: one rule for both domains, computable from annotation alone, Archaea nearly
  unchanged (PRIMARY 138 -> 140), and the margin over the engine reference stays (PRIMARY +71 Bacteria, +20 Archaea).
  (ii) additionally splits the cluster at > 500 nt spacers and strand changes, so it separates str and S10 operons;
  it is the stricter biological reading.
