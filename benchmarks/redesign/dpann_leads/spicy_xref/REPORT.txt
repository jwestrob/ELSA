3. BENCHMARK DESIGN (code/x05_modules.py; each module is OBSERVED domain content plus arrangement, never a system call)
 Elements: lanmodulin-like = 100-200 aa, >= 2 EF-hand loops (overlapping EF-hand Pfam rows merged), every loop-start gap
 within 4.5 aa of 24.5 x k (k 1-3), no other Pfam row (captures 37/49 lut lanM homologs); wide anchor = any 100-200 aa
 EF-hand protein; PQQ dehydrogenase = PQQ or PQQ_2 row, 500-700 aa (the notes' 'xoxF'). Rules: pair = neighbors, same
 strand (head-to-head for LanM|xoxF), gap <= 500 bp (<= 200 for CNNM, Metallophos); chain = <= 1 gene between, one
 strand, every gap <= 500 bp; window = within k genes, used only where the notes never tested strand.
 Tiers (instances lut / earlier database):
   T1 usable on lut now: xoxF+CBB3 637/442, +SBP_bac_3 405/314, +Rieske 94/184, +Lactamase_B 70/85, +Ankyrin 77/67.
   T2 earlier database, multi-genus: Type B 3/267 (18 genera), Type A scaffold S58+R3P 63/310 (43), Type A with any
      EF-hand anchor 32/258 (9), LanM+NarL pair 4/18 (4). Earlier T1 genera: xoxF+CBB3 31, +SBP_bac_3 31, +Lactamase_B
      14, +Ankyrin 10, +Rieske 8.
   T2w within-lineage (one genus on the earlier database): xoxF+Peptidase_C14 11/78, +COXG 1/58, +GFA 8/50, +DctMQP
      1/39, LanM|xoxF 2/137, LanM+CNNM 2/21, SBP_bac_5+LanM 23/40, DUF2158-LanM 0/86 (with Sigma70 0/82).
   T3 too rare or too loose: tannase 0/2, DUF6163 0/2, DUF4394 0/1, Metallophos 0/0, Metal_resist-CcmE 0/0, the
      Hyphomicrobium locus and 571 aa fusion (n 2), beta-roll and small secreted families (no Pfam), mmsB (0/0), the
      ABC/TonB/Response_reg partner classes (domain classes too broad).
 Recovered / resolved (frozen definitions, ribosomal_check on the instance span): recovered = one locus covers >= 50% of
 the span; resolved = it covers >= 80% and >= 80% of the locus lies inside the span (for a neighbor pair, a 2-gene node).
 F1 and excess on the member genes with the frozen lut scorer (best locus by F1, 200 rigid translations).
 Negative controls: (a) truth level: element classes shifted independently within genomes (slice_lut control; lut 100
 replicates, xoxF+CBB3 637 vs 6.7; earlier database 20, 442 vs 5.4, LanM|xoxF 137 vs 0.25); (b) score level: the
 frozen 200 translations applied to recovered and resolved as well as F1 (a random 2-gene interval is 'resolved' 19% of
 the time by the embedding-list tree, which keeps every node); (c) boundary negatives from the failed claims: LanM|xoxF
 head-to-head, transglycosylase beside SBP_bac_5-LanM, YcaO-TfuA-AAA_16 facing LanM, Acyl-CoA_dh >= 571 bp from xoxF.
 Stratify by genome groups: lists exclude a gene's own 0.75 group and recurrence counts groups, so 1-2-group modules
 form a within-lineage stratum (SBP_bac_5+LanM 2 groups, xoxF+Peptidase_C14 2, Type A any-EF 1 in lut).
 Limits: lut was the frozen run's untouched test (FROZEN.json, 2026-11-14): every score here is post hoc. Rules were
