THE ALGORITHM
Input: gene order (contigs of genes) and one whitened ESM++ small vector per gene (zca10). Main unit: a genome -> group
array (emb_hom average linkage at cosine 0.75, 642 groups, from embedding best matches; no taxonomy).

State. Each contig is a sequence of live nodes. A node is a terminal gene or a word instance (a contiguous span: two
child nodes plus 0-2 inserted single genes). A node carries a LIST of aligned instances in other genomes in place of a
label. A terminal gene's list is either its ranked zca10 neighbour list (unique-sequence kNN k 2,000 expanded to genes,
identical copies sharing the tail rank, depth K) or its ws_calib list (the best gene of every genome with within-genome
z >= cut, ranked by z); the gene's own group (or own genome, for the group-free arms) is excluded. A word's list is the
set S of spans in other genomes that supported its creation; a span's rank is the worse rank of its two parts.

Support. For live nodes x, y on one contig with <= 2 intervening single terminal genes,
   S(x, y) = {(p, q) : p in list(x), q in list(y), p and q on one contig of another genome, disjoint, <= 2 genes apart,
              either order, either strand}, keeping for each q the best-ranked p (|S| <= |list(y)|).
n = 1 + supporting units (groups in the main arm, genomes in syn/ctx/gen), and the expectation under random order within
each genome
   E = own term + sum over units u of [1 - prod over genomes G in u of (1 - min(1, 6 c_x(G) c_y(G) / m_G))],
c = list entries in G, m_G = genes of G (for single genomes this is softrec's E, reproduced exactly).

Objective. Lambda(n, E) = n ln(n/E) - n + E nats (Poisson log-likelihood ratio = code-length saving of naming the merge,
stage 1's statistic); a merge needs n >= 2 and Lambda >= tau. syn: Lambda_genome x N_eff / n with N_eff = n / (1 + (n - 1)
s_bar), s_bar the mean pairwise synteny retention S(g, h) over the carriers (own genome + <= 63 sampled supporting genomes),
S(g, h) = share of g's supported round-0 adjacencies that h supports, symmetrised; N_eff >= 2. ctx (exploratory): the same
with s_bar from +-50-gene context vectors outside the instance span, noise floor removed (z 2), <= 32 sampled genomes.

Updates (one round). (A) For every live adjacency, mark the positions next to each entry of list(x) (<= 3 away, same
contig), probe the entries of list(y), count supporting units and accumulate E per genome. (B) syn / ctx: N_eff for the
adjacencies with Lambda >= tau. (C) Greedy commit in decreasing Lambda (ties: left position, distance): an adjacency
commits if its two nodes and the genes between them are unclaimed. (D) Each commit becomes a word node whose list is S
(duplicate spans removed, sorted by rank). Rounds repeat until nothing commits. A word grows by progressive local
alignment against every genome at once; each of its instances may have a different composition and different inserted
genes, and identity is never exact.

Stopping rule. tau = smallest value of {4, 6, 8, 10, 12, 15, 20} whose round-0 instance FDR (mean over 3 within-genome
gene-order shuffles of the passing adjacencies, over the observed count) is <= 0.01; the shuffled runs keep the lists
(vectors do not depend on order) and recompute positions, contexts and the synteny matrix.

Readings. V-top = top-level word instances; V-nest = V-top plus their direct children that are words (selected on odd
for every arm). Diagnostic V-phr (amendment_3; never selectable): V-nest plus chains of nodes joined where the junction's
gene pair passes the arm's own test.

Complexity. Per round O(sum over adjacencies of |list(x)| + |list(y)|) for marks and probes (about 2 x 10^10 at round 0,
depth 1,000) + O(sum over commits of |S| log |S|) for new lists; memory O(sum |list|) (21.5 GB for depth-1,000 lists,
26 GB for z10.6) plus live word lists (226 M entries after round 0, 75-110 M at the end). syn adds one 3,564 x 3,564
matrix per order (one pass, 43-55 s).

Measured run time (biotite, 64 threads; results/job_*.json)
  lists: zca10 kNN -> genes 158-164 s (770 s when the vector file read was I/O-bound); z table -> genes 101-279 s
  round-0 pass A 43-70 s (depth 1,000 / z10.6), 8-11 s (depth 200); pass B (N_eff) 75-97 s; synteny matrix 43-55 s
  full observed run: grp 527 s (25 rounds), syn 484 s (11), z10.6 529 s (16), z13.7 363 s (26), grp200 142 s (22),
  ctx 512 s, gen 218 s; whole job per list source incl. 3-shuffle ladder: 26 min (grp + grp200), 36 min (z10.6 + z13.7),
  66 min (syn + ctx + ctxshuf + gen). Scoring ~15 s per reading; word classes 20-190 s; 15-NN on word vectors ~8 min.

CAVEATS
- tau* = 4 for depth-1,000 lists is the lowest ladder value; tau 6 is an order of magnitude stricter (FDR .0008-.001).
- The selected output's list source (ws_calib z table) is a post hoc handover of ws_calib, evaluated here under the
  predeclared rule; it is embedding-derived (whitened cosine z-scores per genome) and carries no family or taxonomy.
- The context arm was demoted to exploratory at amendment_2 after ws_context's report, before any number of it existed.
- The main-arm selection pool in the code was stale (ctx in place of grp); the predeclared pool gives the same winner.
- Vector classes use igraph's Leiden (same modularity-with-resolution objective as ws_locusspace's leidenalg call); the
  leidenalg solver needed > 8 min per resolution on 0.5 M words.
- Word lists keep one supporting p per q, so a word's list is bounded by its right node's list; a symmetric choice
  would give slightly larger lists.
- Two jobs read the 9.8 GB vector file I/O-bound (lists 770 s instead of 160 s); results are unaffected.
